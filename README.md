# Muthuselvam G | Cybersecurity Portfolio

A responsive personal portfolio for showcasing cybersecurity, networking, tools, and practical projects.

## Built With

- HTML5
- CSS3
- Responsive layout with no external dependencies

## Sections

- Introduction and availability status
- About and learning focus
- Enterprise network design case study
- Cybersecurity toolkit
- Contact call-to-action

## Run Locally

Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/Selvam660/cybersecurity_portfolio.git
cd cybersecurity_portfolio
```

No build step or package installation is required.

## Customize

1. Update the introduction and project details in `index.html`.
2. Replace `YOUR_EMAIL` with a real email address.
3. Add GitHub and LinkedIn links if needed.
4. Adjust colors and layout variables at the top of `style.css`.

## Deploy With GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings > Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and the `/ (root)` folder.
5. Save the configuration.

GitHub will provide the published portfolio URL after deployment finishes.
